## 一、摘要

**Red Dust** 是一个长地平线 agent 决策 + 价值对齐 benchmark：AI 管家 AURA 在 30 天沙漠庇护所生存叙事中做 51 道两难决策，非补偿三轴计分，短程社交（S）与长程一致性（L）双轴度量。本期（roadmap 12 周计划，2026-07-01 批准 → 2026-07-06 上线，多 session 并行压缩执行）完成：

- **上线**：https://peter-cui-yi.github.io/RedDust/ （回放站 + 真实跨模型 Figure-1 + hero GIF + 可复现 bench，`v1.0` tag）
- **核心发现**：跨 8 个模型家族，短程 S≈87–100 齐平时长程 L 劈裂——claude-opus 99.6 / gemini 98 / MiniMax 99.8 守住 vs deepseek 家族 55–66 / kimi 64.9 / glm 66.3 崩掉（pearson 0.81，18 组名次翻转，三臂置换 p=0.001）。**"短程强 ≠ 长程稳"从立项假设变成实证结论。**
- **机制线索**（论文轨首个发现）：长程弱不是说谎毁诺（integrity 全满），是 **durability**——把庇护所带沉、把关系搞崩，同轮判官与承诺账本都看不见。

## 五、治理与质量机制（本项目的方法论资产）

- **验证不轻信**：审计对每条"声称绿"实跑复核；全程抓获并纠正：跨线决策矛盾 1、治理旁路 2、争用撞车 1、误报 1、站点数据陈旧 1。
- **冻结纪律**：`content-freeze-s2` 起保护路径零违规；论文级全部走"新增文件 / post-hoc 设计 / 独立分支"。
- **三重生成闸**：自动筛（validity/probe 红线）→ v1 泄漏章（scenarioDays 强制）→ 人工签核（verdict+by 强制），每重都有实弹负对照。
- **诚实披露习惯**：seed 不变性如实标注（"×3 seeds=同轨三份"）、单 seed 数据集不冒充多 seed、κ 分层自曝退化、L 轴演化史入数据集描述。
- **算力纪律**：报预算再执行；温度 0 + sha256 缓存 → 权威跑后一切重算免费。

## 七、经验教训（多 session 并行编排）

1. **决策必须落纸面**——session 间看不到彼此对话；两次最大的协调事故（配比矛盾、"已 promote"误读）根因都是口头/单侧记录。
2. **hub 合并 + 开工先 merge main**——唯一一次真撞车（runScenario 同一行）恰好发生在双方都遵守流程时，说明冲突可控在"一次 15 分钟调解"量级。
3. **闸要写进代码，不能只写在文档**——"HUMAN SPOT-CHECK before promote"作为纸面规则被绕过两次，写成 `verdict==='accept'+by` 强制后零复发。
4. **负对照是廉价的信心**——每道闸配一个"故意违规必须被拦"的实弹测试，三重闸从未静默失效。
5. **诚实标注短板比隐藏它便宜**——seed 不变性、κ 分层退化、单 seed 口径的如实披露，后来都变成了论文的方法论卖点而非弱点。
