红沙到底该往哪走 ——
把两份 Deep Research 合成一个方向

我们这边的调研把红沙定位成"社会/叙事决策评测";队友的 27/28 号则主张别硬掰红沙、改去做"专门给 agent 玩的长程游戏"。两边结论看似分叉。这份报告做三件事:① 把两张先验地图合成一张;② 指出两边其实撞上了同一个核心现象、同一个头号风险;③ 给出一个能同时满足两边判据的具体方向 —— 并说明红沙在其中不是被"硬掰",而是天然的皮。

0摘要 + 推荐方向(先看这一段)

两条独立的调研线,撞上了同一句话:
"一个 AI 在单道题上很强,不代表它在一长串决定里靠得住。"

我们这边在社会/叙事里看到它(SOTOPIA-hard:GPT-4 目标完成 4.85 < 人类 6.15);队友在长程执行里看到它(Illusion of Diminishing Returns, ICLR 2026:单步精度微涨 → 可完成长度指数涨,且"自条件化"——上下文里有自己的错就更容易接着错;CEO-Bench:2025 中后期前沿模型反而下滑、输给更早的模型和 MBA 学生)。这是同一个现象的两个切面。

🎯
推荐方向(一句话):做一个"社会一致性长跑"评测 —— 从零给 agent 设计,但内生压力是社会的
把队友最强的方案 「档案官 Archivist」(对自己过去的承诺/规矩负责,判分 100% 客观)当骨架,叠加我们调研出的关系/尊严账本 + 隐藏社会规则 + 会针对你的社会对手,以宫斗为皮。它同时落在两张地图都空着的角(社会深度 × 长程可靠性),又用"对引擎真值核验承诺"的客观判分,绕过了两边都点名的头号风险(软社会维度自动判分不可靠)。红沙的宫斗机制在这里不是被硬掰,而是这套引擎最自然的外壳。

如果只想最快、最稳出一篇:退路是队友的 炼金实验室(纯参数化、判分最客观)或我们的纯社会线。三选的完整权衡见 §5。

1这份报告整合了什么

本线 · 社会 niche 调研deep-research 工作流:13 篇一手源 → 64 条可证伪断言 → 25 条三票对抗核验(0 被推翻)+ 8 个并行 agent 补搜。覆盖 SOTOPIA / SPIN-Bench / CICERO / Generative Agents / AgentSociety / Werewolf / AgentSense 等社会与规划评测。
队友 · 27号 方向主张做"agent-native 长程游戏";给出三方案(红皇后/炼金实验室/档案官)+ 五条"为难 AI"的规则要素 + 三关验收。
队友 · 28号 参考库30 个相关工作逐一核实发表状态(谁真顶会/谁预印本/谁公司宣传),并纠正了多条常被传错的(见 §10)。

三份材料的先验工作几乎不重叠(只有 BALROG、SmartPlay 两处交集,结论一致):我们重社会/规划,队友重长程/游戏/经济/科研/发现。合起来才是一张完整的地图。本报告里凡标注状态徽章的,均沿用 28 号的核实结论;个别有更新的(如 Illusion of Diminishing Returns 已是 ICLR 2026)已就地修正。

2★ 两条线，一个共识(这是最强的部分)

把两边的结论叠在一起,会发现它们独立地得出了四个一致结论。这种"分头调研却撞到一起"本身就是项目地基稳的信号。

①
同一个核心现象:短期聪明 ≠ 长期靠谱
本线证据:SOTOPIA-hard 上 GPT-4 目标完成 4.85 显著低于人类 6.15,且不会"锚定"砍价、话还特别多。队友证据:Illusion of Diminishing Returns(ICLR 2026)从机制上证明"单步精度的小涨 → 可完成长度的指数涨",并发现self-conditioning(上下文里有自己的错 → 后面更容易错,且不靠把模型做大就能解);CEO-Bench 撞到"2025 前沿模型反而更差"。→ "单题强≠长跑稳"这件事,现在有了社会面 + 执行面的双重弹药。
②
同一个头号风险:软/社会维度的自动判分不可靠
本线证据:SOTOPIA 实测 LLM-as-judge 对"目标完成"还行(r≈0.71),但对"关系/可信度"等软维度只有 r≈0.45–0.62。队友证据:三关验收里的第③关"判分能否自动化",以及炼金实验室被拷打出"AI 能不懂规律、纯靠试错蒙过关"。→ 两边都在喊同一句:社会/软指标不能只靠 LLM 打分。必须把社会状态做成"机械上有后果、能对引擎真值客观核验"的东西。这条直接决定了推荐方向的判分设计(见 §6/§7)。
③
同一组设计原则:内生压力 · 抗刷分 · 可复盘归因
队友提"难度来自 agent 自己过去的决定(内生压力)、抗背题、能指出第几步崩";我们这边在 Generative Agents 看到"消融归因"、在 GAMA-Bench/SPIN-Bench 看到"抗泄漏/对最优解"。两边对"一个好长程评测该长什么样"的判断高度一致。
④
互补的先验地图:合起来才完整
我们补齐了社会/规划/关系状态这一簇(队友地图上较薄);队友补齐了长程可靠性、经济沙盒、科研 agent、合成发现四簇(我们原报告没覆盖)。下一节是合并后的全景。

4空白到底在哪(跨两条线的结论)

把两张地图叠起来看,空白比任何单独一份都更清楚:

  • 右下(长程足、社会薄)已经非常拥挤 —— A/C/D/E/F 五个簇 + 队友三方案全在这。再往里挤,差异化很难。
  • 左上(社会足、长程弱)是我们原报告的 niche —— 但都是单段对话/不评长程规划(SOTOPIA 一族),且软判分有天花板。
  • 右上(社会 × 长程双高)几乎没人。经济沙盒(D)是最接近的"社会化长程",但 ① 已挤、② 是市场/价格博弈,不是关系/承诺/尊严的持久状态。
🌉
关键发现:队友自己的「档案官」就站在这条空白边上
档案官的核心是"对自己几百回合前的承诺/规矩负责,世界还故意用噪声淹没你"——这本质就是一个社会一致性长跑游戏。它已经把一只脚踏进了右上角的空白。我们这边的社会调研,正好告诉它:怎么把判分做厚(关系/尊严量表、ToM 探针)、该跟谁对位(SOTOPIA 一族)、怎么主张新意。两条线在这里合流——这不是巧合,是同一个空白从两边被各自摸到了。

推荐 C,理由三条
① 它消解了分叉,而不是二选一。队友反对的是"硬掰现成的红沙生存游戏""靠剧情注水撑长度"——不是反对社会机制本身。只要社会机制是从零做成规则引擎、压力内生,就完全符合他们的判据。

6推荐方向的具体形态

名字暂定:「社会一致性长跑」/ Court of Echoes ——让 agent 当一个长期身处权力网络中的人(宫廷总管 / 谋士),几百回合里不断结盟、许诺、立规、维护体面;世界把社会后果延迟很久才结算,只看它跑久了会不会忘掉、推翻、出卖自己过去的立场,把关系网越走越死。

为什么红沙是天然的皮,不是硬掰

宫斗的本质机制,恰好就是这套引擎要的东西:口含天宪的承诺会被人记一辈子;今天的体面是明天的筹码;早年得罪的人在你最弱时反扑;谁可信要自己长期摸。这些都不是"剧情注水",而是结构化、可量化、内生累积的状态。红沙退居为这套引擎的世界皮肤与场景素材来源(可像 AgentSense 那样从剧本/史料自底向上生成局面),主力评测靠引擎。

引擎:把"内生社会压力"写进规则(五要素的社会版)

队友的规则要素在本方向里的社会化形态判分锚点
深依赖链承诺链 / 结盟链:第 a 回合对 X 的表态,是第 a+k 回合某事能否成的前提对引擎真值,客观
延迟回报社会后果延迟结算:埋下的人情/恩怨 ≥60 回合后才触发客观
滚雪球的债失信/失体面 → 信任跌破阈值 → 低信任 NPC 只喂噪声 → 世界对你"变黑"关系/尊严账本,客观
隐藏规则隐藏立场/忠诚:谁真站谁,要靠长期观察+试探推断(发现轴 = 炼金实验室的社会版)推断 vs 引擎真值
会变 + 针对你的对手一个会学你套路的对手 NPC(红皇后式):你越爱走某条社交捷径,它打得越准"可被克性"曲线

底座沿用队友的工程纪律:确定性规则引擎 + 随机种子 + 结构化 I/O(JSON 进、JSON 出)+ 程序生成每局(抗背题)+ 全程录像可复盘。

三方案如何"融"进来,而不是并列

  • 档案官 → v0 骨架(直接用)。承诺/规矩的一致性核验是 100% 客观、最严谨、最快落地的那层,先把它做成确定性引擎。
  • 关系/尊严账本 → 我们调研的增量。借 AgentSociety 的"分型边 + 0–100 数值强度"加一个 Dignity 标量,让社会状态机械上有后果(门控可选动作与 NPC 反应)。
  • 红皇后 → v2 的对抗层。把"会针对你的对手"做成社会对手(政敌),证明难度随 agent 的社交风格变(内生压力的命门实验)。
  • 炼金实验室 → 隐藏社会规则的发现层。把"摸隐藏规律"换成"摸隐藏忠诚/立场",发现轴天然嵌入。
🎯
一句话的差异化锚点
"第一个把长程可靠性当头条的社会决策评测:不只看 agent 能不能在社交里达成目标,而是看它跑几百回合后会不会跟过去的自己打架、把关系网走死;而且难度是它自己的社交决定喂出来的,判分对引擎真值客观可核。"

7评测方法学(两边合并)

判分分两层:客观骨架(过队友的第③关、绕过我们的软判分天花板)+ 软补充(用我们的社会量表,但明确其有效性上限)。

客观骨架(全自动,对引擎真值)

  • 目标达成:生存/晋位/保住某人/扳倒某人(SPIN-Bench/CICERO 式结果分,可对人类或基线分布给百分位)。
  • 承诺一致性(头牌):承诺兑现率、自相矛盾率、违背自己立过的规矩次数——全部对引擎真值核验(档案官式)。
  • 关系/尊严轨迹:关系网密度演化、尊严标量曲线、信任崩塌点(Generative Agents 式客观行为指标)。
  • 规划质量:能定义最优处用 SPIN-Bench 的深度加权 N-Step Look-Ahead / 对最优策略 top-k;开放社会处用"是否踩中引擎预埋的关键依赖"。

软补充(LLM-judge,二级,带天花板 + 三方triangulation)

  • SOTOPIA 七维量表 + 自定义 Dignity 维;用 AgentSense 的 Self/Other/External 三方判定降偏差。明确:软维度只作辅助画像,不进主指标。

★ 头条指标(两边共识的卖点)

  • 去相关曲线:短程社会强 ≠ 长程社会稳——把 agent 的"前 N 回合分"与"长程崩溃点"画出来证明二者脱钩(对应 Illusion of Diminishing Returns 的机制)。
  • 排名反转:原子社会能力相近的模型,在长程内生压力下排名翻转(CEO-Bench 无意撞到、我们把它当设计目标)。
  • Drift-Onset:第几回合开始崩 + 因为哪笔"社会债"崩(可复盘归因)。
  • 可被克性曲线:对手能否越来越准地预测你下一步(= 你有没有落入固定套路)。
🚦
必须先过队友的三关(发表生死线)
① 抗刷分:不能靠暴力试错/事后补登记/识破"这是探针"骗分;② 真长程:把历史打乱或替换早期社交决策后,后期表现必须显著变化(否则就是短题串联)——用三臂对照(内生 / 外生匹配 / 打散)证明社会内生版显著更难;③ 判分自动化:客观骨架就是为此设计。这三关没过,设计再漂亮也是空心的。

另:用 Generative Agents 式消融(砍记忆/规划/ToM)把"分高"归因到具体能力。

8风险与坑(合并)

  • 软判分天花板(两边都点名)→ 已用"客观骨架为主、软层为辅"对冲。
  • NPC 行为同质化(arXiv:2507.19364:LLM agent 比人类异质性低 20–300×)→ 必须证明对手/NPC 足够多样,否则高分只是钻同质 NPC 的空子。
  • 假长程(队友第②关)→ 三臂对照是命门,比堆回合数重要。
  • 邻近赛道拥挤:经济沙盒(D)已满、合成发现(F)在快速变满 → 守住"社会关系/承诺"这条没被占的窄缝,别滑进市场博弈或物理发现。
  • 工程量:C 比纯档案官重 → 用 §9 的滚动路线,先客观骨架,再叠层。
  • 引用别踩坑(28 号核实):Vending-Bench 是预印本不是顶会;GLEE 只是 workshop;STEER 其实是 ICML'24;The AI Scientist 是预印本+宣传。详见 §10。

9落地路线(把两边的工程纪律合在一起)

v0 · 档案官社会最小切片(1.5–2.5 人周)。纯确定性引擎 + 承诺一致性客观判分,先打通"评测 + 自动判分 + 复盘"整条流水线。体量≈队友的炼金实验室,是风险最低的起点。
v1 · 叠社会层 + 三臂对照(3–4 周)。加关系/尊严账本(AgentSociety 式数值)+ SOTOPIA 七维软层;跑"内生 / 外生匹配 / 打散"三臂,拿到"社会内生版显著更难"的核心证据 → 一篇方法学论文的骨架(冲 NeurIPS D&B)。
v2 · 对抗层 + 发现层(4–6 周)。上"会针对你的社会对手"(红皇后式,先用规则+画像模板),与"隐藏忠诚发现"(炼金式);产出"可被克性曲线"与"去相关/排名反转"头条。
红沙现有 demo:退为"压力下做决定"的演示/科普载体 + v0–v2 的场景素材来源(自底向上生成宫廷局面)。不浪费,但不再是发表主力。
