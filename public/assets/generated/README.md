# Generated Red Dust Pixel Assets

The assets in this directory are generated source SVGs for the playable Red Dust demo.
They are grouped by category and referenced by `src/data/asset-manifest.generated.ts`.

The `image2` folder contains generated bitmap art that is also used by the running demo through `src/data/image2Assets.ts`.

- `bunker-cross-section.svg`: 2.5D side-view shelter background
- `red-sand-skyline.svg`: external red sand wasteland skyline
- `broken-wall-module.svg`: damaged shelter wall module

- `pipe-cable-bundle.svg`: pipes and exposed cable bundle
